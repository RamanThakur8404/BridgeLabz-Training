## 📅 Day 1 – Java 8: Lambda Expressions, Functional Interfaces & Method References  
*(Date: 27-Jan-2026)*  
**Focus:** Functional Programming Enhancements in Java 8  

On this day, I studied **Java 8 functional programming concepts** to write cleaner, more expressive, and efficient Java code.

### Key Learnings
- Learned **Lambda Expressions** to reduce boilerplate code and implement functional interfaces concisely.
- Understood **Functional Interfaces** and their importance in Java 8.
- Worked with built-in functional interfaces:
  - `Runnable`
  - `Callable`
  - `Comparator`
- Created **custom functional interfaces** using the `@FunctionalInterface` annotation.
- Practiced **Method References** to improve readability and reuse existing methods:
  - Static method references
  - Instance method references
  - Constructor references
- Understood **Marker Interfaces** and how they provide metadata to the JVM without defining methods.
- Applied Java 8 features to improve:
  - Code readability
  - Maintainability
  - Modern Java coding standards
- Built a strong foundation for **Streams API** and functional-style programming.
