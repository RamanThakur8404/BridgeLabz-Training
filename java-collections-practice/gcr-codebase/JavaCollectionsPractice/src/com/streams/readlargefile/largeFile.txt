Heap memory stores objects.

Unchecked exceptions occur at runtime.

NullPointerException is an unchecked exception.

Iterator is used to traverse collections.

Comparator is used for custom ordering.

FileReader reads character data.
BufferedReader improves performance.

Deserialization converts bytes into objects.

Thread class creates a new thread.

Packages organize classes.
